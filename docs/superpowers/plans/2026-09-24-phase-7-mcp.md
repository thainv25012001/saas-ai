# Phase 7 — MCP: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a business points its own MCP client at `/mcp` with an agent-bound API key and gets that agent's read tools, under the same tenant rules and the same tool runtime as the chat turn.

**Architecture:** extract the tool runtime from `ChatService` into `app/tools/runtime.py` (no behaviour change); add `api_keys` (RLS) plus one `SECURITY DEFINER` lookup function; build a low-level `mcp` v2 `Server` whose `tools/list`/`tools/call` handlers resolve the caller's agent per request, mount it at `/mcp` in stateless JSON mode behind bearer auth, and expose key management through GraphQL and an "MCP access" card on the agent page.

**Tech Stack:** FastAPI 0.141, Starlette 1.6, `mcp>=2.2,<3` (new dependency), SQLAlchemy 2.0 async, Alembic, Strawberry, Redis limiter; Next.js, urql, vitest.

**Spec:** [docs/PHASE-7.md](../../PHASE-7.md), extending [docs/ARCHITECTURE.md](../../ARCHITECTURE.md) §3.1 and §8. **Verified SDK facts:** `C:/Users/Administ/AppData/Local/Temp/claude/c--code-saas-ai/8c603640-a21f-4cad-8ece-00d0d6f88d95/scratchpad/mcp-v2-findings.md` (source-cited, with a run-tested embedding snippet in its last section). ## Global Constraints

- Python **3.12**, `uv`; API code under `apps/api/app/`. **GNU `make` is NOT available** — run underlying commands directly.
- Async tests use **`anyio` only** (`pytestmark = pytest.mark.anyio`); `pytest-asyncio` is deliberately absent.
- The suite runs with `filterwarnings = ["error"]` — any warning fails it.
- **No test may make a network call.** MCP tests run in-process against the ASGI app (`httpx.ASGITransport`).
- **Integration tests need all three overrides in every shell invocation:**
  ```sh
  export DATABASE_URL="postgresql+asyncpg://app_user:app_user_password@localhost:5432/saas_ai"
  export MIGRATION_DATABASE_URL="postgresql+asyncpg://app_owner:app_owner_password@localhost:5432/saas_ai"
  export REDIS_URL="redis://localhost:6379/0"
  ```
  Start infra with `docker compose up -d --wait db redis`. **Check no other `pytest` is running before starting one.**
- Tenant-owned tables get `organization_id UUID NOT NULL` + RLS via `enable_rls(op, table)`. Never inline policy SQL.
- **Two-layer tenancy is mandatory:** an explicit `organization_id` predicate *in addition to* RLS, on every query.
- **PostgreSQL FK checks bypass the referencing session's RLS.** Any INSERT establishing an FK (`agent_id`, `created_by`) needs a scoped ownership SELECT first.
- Primary keys are `app.core.ids.uuid7()`.
- **A plaintext API key never reaches a log line, an error message, the database, or any response other than `createApiKey`'s.**
- `ruff check .`, `ruff format --check .`, `mypy --strict app/` must pass.
- Conventional Commits ending with exactly:
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`

## Review Focus

1. **A revoked key, or a key whose agent was disabled, used in the next request** — 401, with no stale cache. Pinned in Task 3.
2. **A tool the agent is granted but MCP does not expose (`create_lead`), called by name** — JSON-RPC error; nothing runs, nothing is written. Pinned in Task 3.
3. **Org A's key calling `get_product` with org B's product id** — the ordinary not-found tool result; nothing leaks. Pinned in Task 3.
4. **A request with a `Host` header not on the allow-list** — rejected by the transport, not served. Pinned in Task 3.
5. **The tool runtime move changes nothing for chat** — every existing chat/tool test stays green unmodified except imports. Pinned in Task 1.
